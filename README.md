# JobAstra

JobAstra is an AI-powered career agent designed to help users discover relevant job opportunities, evaluate job fit, prepare personalized applications, and streamline the application process with human approval.

The project combines full-stack engineering with Generative AI and Agentic AI to build a real-world job search and application automation platform.

## Repositories

JobAstra is divided into independent services:

### [jobastra-app](https://github.com/ankitsharma34/jobastra-app)

> Not started

The full-stack SaaS application responsible for the web interface, user profiles, job discovery, application management, authentication, and backend workflows.

**Tech:** TypeScript · Next.js · Node.js · PostgreSQL · Redis

**Repository Link:** https://github.com/ankitsharma34/jobastra-app

### [jobastra-ai](https://github.com/ankitsharma34/jobastra-ai)

> Under development

The AI engine responsible for LLM workflows, career intelligence, job matching, RAG, application generation, tools, and agentic workflows.

**Tech:** Python · FastAPI · LLMs · LangChain · LangGraph · RAG

**Repository Link:** https://github.com/ankitsharma34/jobastra-ai
